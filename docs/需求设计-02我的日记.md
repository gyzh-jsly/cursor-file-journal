# 记录模块需求规格说明

## 一、模块概述

**记录**是一个以日历为索引的个人日记模块，用户可通过两种方式将日记内容纳入系统：**写日记**（系统内新建）和**过往归档**（批量导入往期日记）。日记以日期为核心组织，支持修改窗口期（中午前/后规则，最多3次），窗口期过后内容冻结，冻结后可通过段评和整篇备注继续与过去对话。年历作为纯展示入口，用于回顾日记分布，而非新建日记。

模块包含两个子模块：**写日记**、**过往归档**。

**与卷宗模块的关系：**

```
左侧边栏
├── 卷宗
│   ├── 监控目录
|   ├── 手选文件
│   └── 档案库
│
└── 记录
    ├── 写日记
    └── 过往归档
    
```

## 二、子模块1：写日记

### 2.1 功能描述
用户通过月历视图查看日记分布，点击日期查看当日日记列表，支持创建、编辑、查看日记。

### 2.2 月历视图
- 默认展示当年当月日历。
- 有日记的日期以荧光色标注，角落显示当天日记篇数。
- **只有有日记的日期可点击**，无日记的日期不可点击。
- 支持年份和月份切换，可查看任意年月。

### 2.3 日记列表（点击日期后）
- 以圆角卡片流展示当日所有日记。
- 每张卡片显示：
  - 创建时间（定义见2.5）
  - 初见天气
  - 正文预览（前50字）
  - 修改次数徽章
- 支持按创建时间或最后修改时间排序。
- 支持置顶功能。

### 2.4 日记创建
- 点击「写日记」按钮，在标签栏打开新标签页。
- 内容区域为模拟 Word 的大文本输入框。
- 天气：**自动获取**（调用天气API），不展示给用户选择。
- 提交后自动归属当天日期，记录创建时间（精确到秒）和初见天气。
- 支持勾选「置顶」。

### 2.5 日记修改规则（双标时间窗口）
- 上午创建（00:00 - 11:59）→ 截止到当天 23:59:59。
- 下午创建（12:00 - 23:59）→ 截止到创建时间 +24h。
- **截止时间计算的基准始终为原始创建时间**，非最后修改时间。
- 窗口内最多修改 **3 次**，超时或超次后锁定，不可编辑。
- 卡片上展示的**创建时间**为：
  - 从未修改 = 首次创建时间
  - 修改过 = 窗口期内**最后一次修改的时间**（冻结后不变）
- 修改次数达到3次后，即使仍在窗口期内，也不再允许修改。
- 前端**不展示**剩余修改时间（隐藏规则）。
- 超限/超时提示：“已超过修改窗口期”或“修改次数已达上限”。

### 2.6 日记详情与段评/备注
- 点击卡片进入日记全文页。
- 支持**段评**：划选文字后添加评论，关联日记版本号（`modify_count`）。
- 支持**全文备注**：标题栏右侧「注」图标，有备注时变绿并显示条数气泡。
- 备注可叠加追加，格式为 `[序号] [日期] [内容]`。
- 段评和备注通过**悬浮窗**展示，**可拖拽**。

### 2.7 段评存储与定位
- 每条段评存储：
  - `version`：添加段评时的日记版本号（`modify_count`）
  - `start_offset`：起始偏移量
  - `end_offset`：结束偏移量
  - `selected_text`：原文片段
- 段评详情页展示原文片段，方便用户对照校准。
- **不记录**修改时的天气、修改备注、内容快照。

### 2.8 段评与日记修改冲突处理
- 当用户修改包含段评的日记时，**每次修改保存前**弹出温和提示：
  > “当前日记有段评。修改正文可能导致部分段评位置偏移，建议修改前先记录相关段评原文。”
- 系统不自动校准偏移量，不强制删除段评，由用户根据提示自行决定是否继续修改。
- 修改后：
  - 若偏移量有效（原文未变）→ 段评正常定位
  - 若偏移量失效但原文片段可匹配 → 按原文片段重新定位
  - 若原文已被删除或无法匹配 → 前端展示时标注：
    > “原文已修改，此段评基于旧版本”
- `version` 字段的作用：用户修改后，段评对应的原文已被删除。此时偏移量无法解决，`version` 可判断当前版本 > 段评版本，明确告知用户“段评基于旧版本”。

## 三、子模块2：过往归档

### 3.1 功能描述
通过文件批量导入往期纸质/电子日记。导入的日记仅在【过往归档】子模块内按批次分组展示，不进入月历视图。

### 3.2 入口
- 左侧边栏【记录】→【过往归档】，右侧主内容区显示导入界面。

### 3.3 页面布局

```
┌─────────────────────────────────────────────────────────────────┐
│ 📦 过往归档                                                      │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│ ┌─────────────────────────────────────────────────────────────┐ │
│ │ 格式说明：每篇日记之间用两个空行分隔。系统只负责按空行切割。   │ │
│ └─────────────────────────────────────────────────────────────┘ │
│                                                                 │
│ ┌─────────────────────────────────────────────────────────────┐ │
│ │ [ 📁 选择文件 ]  已选：D:\日记\2023年合集.txt                │ │
│ └─────────────────────────────────────────────────────────────┘ │
│                                                                 │
│                              [预览解析]        [清空]            │
│                                                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│ 预览解析结果：                                                   │
│                                                                 │
│ ▼ 导入批次 #1（预览）                                            │
│   ┌─────────────────────────────────────────────────────────┐   │
│   │ 日记 #1                                  [编辑] [删除]   │   │
│   │ 内容预览：今天去了颐和园...（前50字）                      │   │
│   └─────────────────────────────────────────────────────────┘   │
│   ┌─────────────────────────────────────────────────────────┐   │
│   │ 日记 #2                                  [编辑] [删除]   │   │
│   │ 内容预览：那年夏天一直在学吉他...                         │   │
│   └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│                                          [确认导入]              │
└─────────────────────────────────────────────────────────────────┘
```

### 3.4 支持的文件格式
- 首期支持：`.txt`、`.md`（纯文本）
- 预留扩展：`.docx`、自动提取日期等

### 3.5 格式规范
- 每篇日记之间用**两个空行**分隔。
- 系统**不解析**日期、天气等内容，只负责按空行切割。
- 日期、天气等信息用户写在日记正文中即可。

### 3.6 文件选择
- 用户点击 [📁 选择文件] 按钮，通过系统文件选择器选取文件。
- 后期扩展：支持拖拽文件。

### 3.7 预览解析
- 点击 [预览解析] → 读取文件内容，按两个空行切割。
- 预览区展示解析结果，按“导入批次 #1（预览）”分组。
- 预览区支持：
  - **编辑**：弹出小窗修改单篇日记的内容
  - **删除**：移除此篇日记（不导入）
  - ❌ 不支持新增（必须回到文件修改后重新解析）
- [清空] 按钮：清空已选文件 + 清空预览区。

### 3.8 确认导入
- 点击 [确认导入] → 正式入库。
- 导入后，批次名变为实际导入时间（如“导入批次 #1 - 2026-05-04 14:30”）。
- 导入的日记**不进入月历视图**，仅在【过往归档】子模块内展示。

### 3.9 重复导入处理
- 允许重复导入同一文件。
- 按导入批次分组展示，每次导入产生一个独立分组。
- 分组命名：“导入批次 #1 - 2026-05-04 14:30”、“导入批次 #2 - 2026-05-05 10:15”。
- 每个分组支持：
  - **删除批次**：删除该批次下所有日记
  - **单篇删除**：删除分组内的单篇日记

### 3.10 导入日记的展示与操作
- 卡片样式与“写日记”卡片保持一致。
- 卡片底部显示元信息：
  > 来自：2023年合集.txt ｜ 导入于：2026-05-04 15:30
- **确认导入后，日记内容永久锁定，不可修改、不可编辑**。
- 删除方式：删除批次 或 单篇删除。

### 3.11 界面操作汇总

| 操作           | 说明                             |
| -------------- | -------------------------------- |
| 选择文件       | 点击按钮浏览选择文件             |
| 预览解析       | 按空行切割文件内容，展示在预览区 |
| 编辑（预览区） | 修改单篇日记的内容（导入前）     |
| 删除（预览区） | 移除此篇日记（不导入）           |
| 清空           | 清空已选文件和预览区             |
| 确认导入       | 正式入库，生成批次分组           |
| 删除批次       | 删除整个批次的所有日记           |
| 删除单篇       | 删除批次内的单篇日记             |

## 四、界面结构汇总

```
左侧边栏
├── 记录
│   ├── 写日记 → 标签栏打开新标签页（大文本输入框）
│   └── 过往归档 → 右侧：文件导入 + 批次分组列表
│
└── 卷宗（略）

月历视图（独立页面，仅展示“写日记”创建的日记）
日记列表（点击月历日期进入，展示当日“写日记”创建的日记）
```
